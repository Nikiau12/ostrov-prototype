# Остров — прототип страницы предзаказа

Интерактивный черновик одностраничного сайта для литературного объекта «Остров», № 1.

В прототипе:

- обложка со снимаемой калькой;
- адаптивная композиция для компьютера и телефона;
- текст о первом выпуске и интерактивные сноски;
- художественный маркер предзаказа.

Текст, ссылка предзаказа и детали оформления остаются черновыми.
